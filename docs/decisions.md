# 决策记录

格式：`D-xxx 标题 — 决定 / 理由 / 代价 / 日期`

- **D-001 翻译引擎默认 Apple Translation**
  - 决定：默认引擎是 Apple Translation（本机离线）。
  - 理由：Lipper 明确说"不需要翻译很准，Apple 自带的就很好"；零网络、零依赖、零费用。
  - 代价：口语和俚语较弱，用 glossary 弥补。其它引擎留作 S3，默认关闭。
  - 日期：2026-10-10
- **D-002 MVP 用贴靠侧栏，不做气泡内嵌**
  - 理由：侧栏只依赖窗口 frame，稳；内嵌依赖每个气泡的 frame 和滚动同步，脆。
  - 安排：内嵌做成 S1。
  - 日期：2026-10-10
- **D-003 不引入第三方 Swift 包**
  - 理由：减少供应链和审查负担，便于开源。
  - 日期：2026-10-10
- **D-004 kmsg 只读子集 vendor 进 Sources/KakaoAX**
  - 决定：不作为依赖引入整个 kmsg。
  - 理由：kmsg 含发送、登录等自动化路径，与本项目只读红线冲突。
  - 日期：2026-10-10
- **D-005 开发期隐私：AI 只看脱敏数据 + 标题白名单的 나와의 채팅**
  - 日期：2026-10-10
- **D-006 只翻可见消息**
  - 决定：不回溯历史，翻译范围由可见集合驱动。
  - 理由：AX 列表可能虚拟化；只读约束下也不能主动滚动。
  - 日期：2026-10-10

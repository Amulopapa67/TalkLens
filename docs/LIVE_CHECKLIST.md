# 真机验收清单（给 Lipper）

> 全部在 **나와의 채팅** 里测，不要拿真实群聊做实验。每项打勾，或者在后面写下现象。
> 准备：`./scripts/build_app.sh`，然后打开 `build/TalkLens.app`。本机用 Apple Development 证书签名，重新构建后辅助功能授权不会丢。
> 数字类指标看 菜单栏 → 关于 TalkLens 里的诊断数字（只有耗时，没有内容）。

## 安装与权限（F2）

- [ ] 首次打开 TalkLens.app，菜单栏出现图标，并自动弹出引导窗口
- [ ] 引导窗口显示辅助功能"未授权"；点「打开系统设置」后跳到 辅助功能 页
- [ ] 在系统设置里打开 TalkLens 的开关后，引导窗口 1–2 秒内变成"已授权"，不用重启 App
- [ ] 翻译语言状态正确；如果在系统设置里删掉韩语，引导窗口出现下载按钮，点击后弹出系统下载框，下载完自动变为"已安装"

## 基本功能（F1、F3–F7）

- [ ] 菜单项都在：启用/暂停翻译、显示/隐藏侧栏、常驻显示、设置…、权限与语言引导…、关于、退出
- [ ] 打开 나와의 채팅，侧栏贴在窗口右侧，显示可见消息的中文
- [ ] 用手机给自己发一条韩语消息，侧栏大约 1 秒内出现译文（关于窗口里"新消息→译文" p50 ≤ 600 ms、p95 ≤ 1500 ms，至少测 20 条）
- [ ] `ㅋㅋㅋ`、表情、链接、数字不送翻译：显示原文，ㅋㅋ 一类带注释
- [ ] 랩미팅、휴강、보강 这类词，译文下方有词表 chip
- [ ] 多行消息的换行保留，没有变成空行
- [ ] 原文可以按条折叠/展开；设置里"显示原文"可以全局开关
- [ ] 鼠标悬停在一条译文上出现"复制"按钮（如果不出现，试右键菜单），复制后粘贴出来是译文
- [ ] 侧栏往上滚时停止自动跟底，出现"↓ 新消息"，点击回到底部
- [ ] 拖动、缩放 KakaoTalk 窗口，侧栏跟随、不闪烁（关于窗口里"侧栏跟随" p95 ≤ 100 ms）
- [ ] 把窗口拖到屏幕右边缘，侧栏改贴左侧；两边都没空间时内嵌在窗口右侧，且不挡输入框
- [ ] 点击侧栏后，KakaoTalk 的输入框仍然有焦点，可以继续打字
- [ ] 切到别的 App，侧栏隐藏；切回 KakaoTalk，侧栏出现
- [ ] 打开"常驻显示"后，切到别的 App 侧栏仍在（层级降为普通窗口）
- [ ] 最小化聊天窗口 → 侧栏隐藏；还原 → 出现
- [ ] 切换到另一个聊天窗口，侧栏内容随之切换（不会残留上一个聊天的消息）
- [ ] 设置里把目标语言改成 English，已显示的消息重新翻译成英文
- [ ] 设置里字号、透明度、贴靠位置、侧栏宽度即时生效；侧栏文字始终不透明，透明度只影响背景
- [ ] "编辑用户词表"会生成模板并打开；加一条词条后"重新加载词表"生效
- [ ] 开机启动开关可用；系统要求批准时，状态显示正确
- [ ] 菜单"暂停翻译"后不再读取和翻译；恢复后继续
- [ ] 只开着 KakaoTalk 主窗口（没有聊天窗口）时，提示"打开 KakaoTalk 聊天窗口"，而且不打扰

## 沉浸式（默认显示方式，D-017）

- [ ] 译文正好盖住气泡里的韩文；自己的消息是黄底，别人的是白底，颜色接近 KakaoTalk；深色模式下也正常
- [ ] 打开一个聊天后几秒内，往上翻到的旧消息也已经有译文（预读、预翻译）
- [ ] 触控板或滚轮滚动（含惯性）时，译文贴着气泡走，停下后不跳；拖滚动条时也跟
- [ ] 新消息到达、KakaoTalk 自动滚到底时，译文跟得上
- [ ] 拖动窗口时跟随；缩放时译文先隐藏，约 0.3 s 后回到正确位置
- [ ] 别的窗口（其它 App，或 KakaoTalk 主窗口、另一个聊天窗口）盖住聊天窗口的一部分时，被盖住的部分不显示译文，没盖住的部分正常
- [ ] KakaoTalk 不在前台、但聊天窗口露在屏幕上时，译文仍然显示在露出来的部分
- [ ] 按住 ⌥ 时全部隐藏、显示原文；鼠标悬停气泡时，出现译文 + 词表卡片
- [ ] 覆盖层不挡任何操作：点选、选中文字、右键、回复、表情回应、在输入框打字
- [ ] 键盘滚动（PageUp / 方向键）没有滚动事件，最多约 1 s 后由兜底轮询纠正——是否能接受
- [ ] 长消息（多行）和很短的消息（如"넵"）：译文缩小字号、加宽、向下延伸后是否好读
- [ ] 菜单和设置里切换"沉浸式 / 侧栏"立即生效
- [ ] 两个以上聊天窗口（含开放聊天、商业账号这类没有输入框的窗口）并排时，每个都自动出现译文，不需要先点一下
- [ ] 在任一窗口上滚动，只有那个窗口的译文跟着动；后面窗口被前面 KakaoTalk 窗口挡住的部分不显示译文
- [ ] 最小化或关闭一个聊天窗口，它的译文消失，其它窗口不受影响；还原后能重新出现
- [ ] 运行几分钟后，KakaoTalk 本身没有变卡（D-020）

## 语言

- [ ] 设置里切换界面语言（简中 / 繁中 / English / 한국어 / 日本語 / 跟随系统），菜单、侧栏、悬停卡片、设置、引导、关于窗口的文字立即跟着变
- [ ] 日文、韩文的长句在设置窗口里换行正常；菜单"界面语言""原文语言""目标语言"子菜单的勾选状态正确
- [ ] 原文语言默认是韩语；改成"智能识别"后，英文、日文消息也会被翻译（缺语言对时出现下载提示）

## 事件与性能（M4）

- [ ] KakaoTalk 在前台、窗口没有变化时，TalkLens 的 CPU ≤ 1%（活动监视器看 60 秒平均，或 `top -l 61 -s 1 -pid <pid>`）
- [ ] 常驻内存 ≤ 120 MB（活动监视器"内存"列）
- [ ] 新消息到达时，侧栏是靠 AX 通知还是靠 1 秒兜底轮询更新的？（`tlctl watch --seconds 60` 期间发一条消息，看是否出现 AXRowCountChanged / AXCreated / AXValueChanged）

## 健壮性

- [ ] 退出 KakaoTalk 再打开，TalkLens 不崩溃，并能恢复
- [ ] 在系统设置里撤销辅助功能权限，侧栏显示"需要辅助功能权限"而不是崩溃；重新授权后自动恢复
- [ ] 外接显示器：窗口在副屏时侧栏位置正确；窗口跨两块屏时也正确
- [ ] 全屏模式、不同 Space、台前调度（Stage Manager）下侧栏表现正常
- [ ] 睡眠唤醒后仍正常
- [ ] 快速上下滚动聊天记录，侧栏不卡顿

## 隐私

- [ ] `~/Library/Logs`、`~/Library/Application Support/TalkLens/`（只应有你自己的 glossary.json）和 `~/Library/Preferences/dev.lipper.TalkLens.plist` 里都找不到消息原文
- [ ] `log show --last 10m --predicate 'subsystem == "dev.lipper.TalkLens"'` 里只有数量、耗时、错误码
- [ ] 断网时一切照常（零网络）

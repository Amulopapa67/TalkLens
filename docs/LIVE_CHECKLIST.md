# 真机验收清单（给 Lipper）

> 初稿，Claude Code 在 M3–M5 补全。全部在 **나와의 채팅** 里测，避免拿真实群聊做实验。
> 每项打勾，或写下现象。

## 安装与权限

- [ ] 首次打开 TalkLens.app，菜单栏出现图标
- [ ] 引导页提示辅助功能权限，点击后能跳到系统设置对应页面，授权后无需重启即生效
- [ ] 未安装韩语或中文翻译语言时，出现系统下载弹窗，下载后能自动开始翻译

## 基本功能（F1–F7）

- [ ] 打开 나와의 채팅，侧栏贴在窗口右侧，显示可见消息的中文
- [ ] 在手机上给自己发一条韩语消息，1 秒左右侧栏出现译文
- [ ] ㅋㅋㅋ、表情、链接、数字不被"翻译"，而是显示注释或原样
- [ ] 랩미팅、휴강 这类词下方有词表 chip
- [ ] 拖动、缩放 KakaoTalk 窗口，侧栏跟随，不闪烁
- [ ] 切换到别的 App，侧栏隐藏；切回来，侧栏出现
- [ ] 点击侧栏不会让 KakaoTalk 失去焦点，输入框没有被挡住
- [ ] 切换到另一个聊天窗口，侧栏内容随之切换
- [ ] 设置里改目标语言为 English，生效
- [ ] 菜单"暂停翻译"有效

## 健壮性

- [ ] 退出 KakaoTalk 再打开，TalkLens 不崩溃，能恢复
- [ ] 在系统设置里撤销辅助功能权限，TalkLens 提示而不是崩溃
- [ ] 外接显示器、全屏模式、不同 Space
- [ ] 睡眠唤醒后仍正常
- [ ] 快速上下滚动聊天记录，侧栏不卡顿

## 隐私

- [ ] `~/Library/Logs` 和 App 的数据目录里找不到任何消息原文
- [ ] 断网时一切照常（零网络）
